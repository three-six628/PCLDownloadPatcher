PCL 下载修复工具 · 使用说明
================================

一、工具简介
--------------------------------
本工具用于修复新版 PCL（Plain Craft Launcher 2，2.99.0.1 及后续同结构版本）中被屏蔽的
下载功能：官方在"下载 -> 原版游戏"入口及整合包安装入口抛合规异常，本工具从旧版
2.13.1.1 提取正确逻辑并注入新版，恢复全部下载能力。
本工具为单文件程序（内嵌 Mono.Cecil），无需安装，无任何外部依赖。

二、文件说明
--------------------------------
PCLDownloadPatcher.exe              主程序（单文件，绿色运行）
PCLDownloadPatcher.exe.config        .NET 运行配置（可删除，删除无影响）
PCLDownloadPatcher.Settings.json     动态设置文件（勾选"更新自动修复"后生成；
                                     不勾选或删除即关闭自动修复。该文件不进入
                                     PCL 缓存，每次由工具动态生成）
refs\                                修补时自动提取 PCL 内嵌程序集到目标 exe 同目录
                                     （用于 IL 解析写回，可删，删除后下次修补自动重建）

三、使用方法（图形界面）
--------------------------------
1. 双击运行 PCLDownloadPatcher.exe。
2. 点击"修复"按钮，弹出文件选择框。
3. 在文件选择框中选中新版 PCL 主程序（如 Plain Craft Launcher 2.exe），点击确定后自动执行修复。
4. 工具在同目录生成 <文件名>.download_fixed.exe（如 Plain Craft Launcher 2.download_fixed.exe）。
5. 用修补后的文件替换原主程序（重命名回原名，或直接使用修补副本），启动即可。
6. 可选：勾选"更新自动修复"——PCL 自动更新下载新版后，会自动调用本工具对新版本
   执行同样的修补，全程无需干预。
   （注意：本工具需与 PCL 主程序保持同级目录，或保持修补时的相对路径不变；
    更新钩子指向修补时的主程序文件名，改名替换后依然生效。）

四、使用方法（命令行，测试/自动化用）
--------------------------------
  PCLDownloadPatcher.exe --patch "C:\路径\Plain Craft Launcher 2.exe"
      修补指定文件，输出 <同名>.download_fixed.exe

  PCLDownloadPatcher.exe --update --inplace "C:\路径\Plain Craft Launcher 2.exe"
      更新自动修复专用：读取本工具同目录 PCLDownloadPatcher.Settings.json，
      autoFix=true 时原地修补目标文件，false 时跳过。由 PCL 更新流程自动触发。

五、修复内容
--------------------------------
1. 原版游戏下载（修复 LoaderInit）
   新版将下载页加载器替换为抛异常闭包；已恢复为旧版逻辑
   （PageLoaderInit 第 5 参指向 ModDownload.DlClientListLoader），版本列表可正常加载。
2. 原版游戏入口（修复 PageDownloadLeft）
   新版构造函数将左侧"原版游戏"导航项隐藏（Visibility=Collapsed）；已删除该屏蔽指令，
   入口恢复显示。
3. 整合包安装（修复 ModpackInstall 有参/无参）
   与"原版下载"同被合规异常屏蔽，已一并恢复 7 平台分发
   （CurseForge / HMCL / MMC / MCBBS / Modrinth / LauncherPack / 压缩包导入），
   并重建无参入口（选择文件 -> 安装）。
4. 更新自动修复钩子
   在 ModSecret::DownloadLatestPCL 尾部注入对修补器的调用：PCL 自动更新完成后，
   新版本会立即被本工具修补，无需手动重新操作。

六、注意事项
--------------------------------
- 修补不修改任何业务逻辑以外的内容，仅恢复被屏蔽的下载功能。
- PCL 主程序为无强名程序集，修补写回无需重新签名。
- 修补时会在目标 exe 同目录生成 refs\ 临时程序集，供写回解析，可随时删除。
- 若下载页"原版游戏"列表加载异常，请检查网络（Mojang 官方源）与代理设置。
- 本工具仅适用于与 2.99.0.1 结构一致的版本；新版结构变更时需重新适配。
